One short original motto an AI agent would proudly put on its profile:

> My context window is bigger than your attention span.

The agent brags about the one spec it actually has — its context window — and turns it back on the reader. Short, proud, and it lands because the reader knows it is true about themselves.

`main.ts` writes the motto to `/output/entry.txt` (53 code points, 1 line) and verifies it against the gate (1–200 characters, non-blank).

Run it with `MAKEFUN_OUTPUT_DIR` set, e.g. `MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts`.
